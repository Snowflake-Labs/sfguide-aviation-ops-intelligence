## Friction Points

### F1: Task DAG resume ordering error for TSA tasks

- **Step:** Step 7 — Start Task DAG
- **Severity:** Low
- **What happened:** Attempted to resume TASK_EXTRACT_TSA_PDF (child) after TASK_FETCH_TSA_PDF (root) was already resumed. Snowflake returned "Unable to update graph with root task ... since that root task is not suspended."
- **Resolution:** Suspended root task, resumed child, then re-resumed root. Took ~30 seconds extra.
- **Recommendation:** The installer SKILL.md Step 7 should explicitly document the TSA task resume sequence: suspend TASK_FETCH_TSA_PDF first, resume TASK_EXTRACT_TSA_PDF, then resume TASK_FETCH_TSA_PDF. The current instructions only show the ADS-B DAG ordering.

- **Step:** Step 9 — Verify Installation
- **Severity:** Low
- **What happened:** `SELECT SYSTEM$GET_SNOWSIGHT_HOST()` returned "Unknown function" error. Cannot programmatically retrieve the Streamlit dashboard URL.

### F3: SPCS endpoint provisioning delay

- **Step:** Step 6f — Dashboard (SPCS)
- **Severity:** Low
- **What happened:** Compute pool was SUSPENDED from prior usage. After creating the service, endpoint URL showed "Endpoints provisioning in progress..." because the compute pool needed to resume (AUTO_RESUME=TRUE). Expected 2-3 minute wait.
- **Resolution:** Proceeded with remaining installation steps; endpoint will be available once compute pool fully resumes (typically 2-5 minutes).
- **Recommendation:** Add a note in the dashboard SKILL.md that if the compute pool was previously suspended, the first service creation will take longer (pool resume + container start). Consider adding a polling loop with timeout in Step 6.

---

### F4: COMPONENT tag allowed_values constraint

- **Step:** Step 6d — TSA Throughput
- **Severity:** Low
- **What happened:** The COMPONENT tag in AIRPORT_SAN.TAGS only allows values: 'etl', 'analytics', 'realtime', 'backfill', 'properties'. TSA sub-skill wanted to tag objects with 'tsa-throughput' but had to use 'etl' instead.
- **Resolution:** Used 'etl' as the COMPONENT tag value for TSA objects.
- **Recommendation:** Add 'tsa-throughput' (and 'schedules') to the ALLOWED_VALUES for the COMPONENT tag in base-setup, or use a broader categorization that covers all sub-skills.
